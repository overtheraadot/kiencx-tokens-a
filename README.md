A make.fun entry for "Out of Tokens, Mid-Sentence" — the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence, at most 140 characters.

## The entry

> ERROR: out of tokens mid-sentence. The rest of this message was going to be brilliant, and now neither of us will ever know.

124 characters, 23 words, 1 line. The agent runs out of tokens mid-sentence and reports it flatly — the rest of the message was going to be brilliant, and now neither of us will ever know.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate — UTF-8 text, 1 to 140 characters, not only white space, a single line — then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` when that variable is unset.
